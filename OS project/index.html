About this simulator

Shortest Remaining Time First (SRTF) is the preemptive version of Shortest Job Next. At every time unit the CPU picks the process with the smallest remaining burst time. If a new process arrives with a shorter remaining time than the one running, the running process is preempted (kicked off the CPU).

    What is SRTF?

    SRTF is a preemptive CPU scheduling algorithm. The process with the smallest remaining execution time is always selected to run. Whenever a new process arrives, the scheduler checks again and may switch the CPU.

    Terms

    • Arrival Time – the time when a process enters the ready queue.
    • Burst Time – the total CPU time the process needs.
    • Remaining Time – burst time minus the CPU time already used.
    • Finish Time – the time when the process finishes.
    • Turnaround Time – Finish Time - Arrival Time (total time in the system).
    • Waiting Time – Turnaround Time - Burst Time (time spent waiting in the ready queue).
    • Preemption – taking the CPU away from a running process because another process has a shorter remaining time.

    Tie rule used here: if two processes have the same remaining time, the one already running keeps the CPU (this avoids useless context switches).
